# Vitel Farms — Verified Field Image Intake

This folder is reserved for current Vitel field photography that has passed the public-use verification gate.

Before an image is published here, record:
- file name;
- capture date or best-supported date range;
- district / location;
- photographer or source;
- rights / permission status;
- people shown and consent status where relevant;
- what the image actually documents;
- whether it is historical, current Vitel activity, or contextual sector imagery;
- reviewer and verification date.

## Publication rule
Do not publish an image as current Vitel operations unless its date, place, rights and Vitel context are adequately supported. Historical TEU imagery must remain labeled as historical. Generic stock photography should not be used to imply Vitel field activity.

No present-day Vitel field photograph has yet been added to this public folder. The archive structure is ready for verified material as it becomes available.
